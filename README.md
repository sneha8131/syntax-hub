# Sales Performance Dashboard - Power BI Project

## Project Overview

This project is an interactive Sales Performance Dashboard developed using Power BI. The dashboard analyzes sales data to provide meaningful business insights such as sales trends, profit analysis, regional performance, customer behavior, and product performance.

## Features

* Total Sales & Profit Analysis
* Regional Sales Performance
* Product Performance Insights
* Customer Analysis
* KPI Tracking
* Interactive Filters & Visualizations

## Tools & Technologies Used

* Power BI
* DAX
* Power Query
* Data Visualization
* Business Intelligence

## Dataset Information

The dataset contains:

* Sales Records
* Product Details
* Customer Information
* Regional Data
* Profit & Revenue Analysis

## Dashboard Insights

The dashboard helps in:

* Identifying top-performing products
* Tracking regional sales growth
* Monitoring profit margins
* Understanding customer purchasing behavior
* Improving business decision-making
